## Como registrar

Crie um `.md` por assunto. Identifique data e fontes quando pertinente. Registre decisões e fatos separadamente de hipóteses; para hipóteses ainda em estudo, use [rascunhos](../scratchpad/README.md). Se um assunto pertencer a um projeto específico, vincule-o ao [índice de projetos](../projects/README.md).

Voltar ao [mapa central](../README.md).
